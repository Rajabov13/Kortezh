# КОРТЕЖ: Успей на работу

Браузерная 3D-игра на three.js. Вы — госчиновник на служебной машине с сопровождением ДПС (ЙПХ),
нужно успеть на работу до начала рабочего дня. Все тексты на русском, управление с ПК и с телефона.

- 11 ролей, 17 машин, 9 маршрутов карьеры, свободная езда и арена
- настоящие 3D-модели машин (Maybach, S-Class, E-Class, Malibu, BMW 7, Audi A8, G-Class, Range Rover, Land Cruiser 200, Camry, Malibu ДПС)
- реалистичные сирены (вой, йелп, хай-лоу, фазер, крякалка), мигалки, флажки на крыльях
- гараж и тюнинг, погода и время суток, события на дороге, режим фото, повтор, задания и рекорды

## Структура

| Папка | Что внутри |
| --- | --- |
| `site/` | готовый сайт: `index.html` (вся игра в одном файле), `models/` (машины), `draco/` (декодер) |
| `src/` | исходники игры: `head.html` (интерфейс и стили) и модули `*.js` |
| `tools/build.mjs` | сборка `src/` → `site/index.html` |
| `tools/models/` | подготовка своих 3D-моделей машин |

## Публикация на Netlify

Сайт уже собран, сборка на Netlify не нужна (`netlify.toml` публикует папку `site/`).

1. Netlify → **Add new site → Import an existing project → GitHub** → выберите этот репозиторий.
2. Настройки оставьте как есть и нажмите **Deploy**.

После этого каждый push в репозиторий будет обновлять сайт автоматически.

## Сборка после правок в `src/`

```bash
npm install
npm run build
```

Команда пересобирает `site/index.html`; закоммитьте его вместе с исходниками.

## Свои 3D-модели машин

```bash
bash tools/models/buildm.sh путь/к/папке-с-scene.gltf lx
```

Скрипт разворачивает модель передом вперёд, ставит на землю, находит колёса (чтобы они крутились),
упрощает и сжимает её и кладёт в `site/models/<id>.glb`. Затем добавьте запись в `site/models/models.json`
(поля описаны в ключе `_help`). Модели подгружаются только на сайте, а не при открытии файла с диска.
